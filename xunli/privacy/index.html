XUNLI / PRIVACY

训练数据，留在你的设备上。

循力无需账号，不向开发者自动传输训练记录，不使用广告、跟踪或分析 SDK。

生效日期：2026 年 10 月 15 日
适用于 Gnod Studio 的循力（XUNLI）iOS 应用与本产品网站。

我们不收集 App 内的个人数据

循力的核心功能在设备本地运行。我们不通过 App 收集、接收、出售或共享你的训练记录、身体或健康数据、身份信息或设备标识。App 没有账号系统、开发者服务器、广告、分析 SDK 或跨应用跟踪。

一次性付费下载由 Apple 的 App Store 处理。App 不包含订阅、应用内购买或外部支付；我们不会通过 App 获取你的支付卡资料。

本地保存哪些内容

App 在自己的存储空间保存训练计划、具体训练日、收藏、未完成训练与输入草稿、完成组的重量/次数/时长、热身或正式组标记、训练历史、备注、主观强度和相关时间，以及训练目标、单位、显示和提醒等偏好。这些内容用于继续训练、回顾与恢复，不会自动上传给开发者。

App 没有云端自动同步。iOS 的设备备份、恢复和文件服务可能按照你的系统设置处理应用数据；这些系统功能由 Apple 或你选择的服务提供者管理。

备份、导入与手动分享

你可以主动将数据导出为 JSON 备份或 CSV 表格，或从自己选择的 JSON 文件恢复。保存位置与接收方由你在系统界面中决定。只有你明确选择导出、分享或导入时，相关文件才会交给所选文件服务或接收方；App 不会自动把文件发送给开发者。

导出的文件可能包含训练时间、重量、备注等个人内容，未额外加密。请只保存到可信位置，并核对分享对象。第三方文件提供者对所选文件的处理受其自身政策约束。

确认导入之前，App 会在本机保留一份导入前的恢复副本，以帮助撤回错误导入。该副本也不会自动上传给我们。

通知与系统权限

训练日提醒和休息结束提醒默认关闭。只有你主动开启时，App 才请求通知权限；提醒由 iOS 在设备本地安排，不使用远程推送服务。提醒可能显示在锁定屏幕，你可以在 iOS 通知设置中调整显示与声音，或随时关闭。

循力不请求访问 Apple 健康、相机、麦克风、照片、通讯录、位置或广告跟踪权限。通过系统文件选择器打开你选择的备份，不等于读取设备上的其他文件。

清除与删除

你可以在「设置 → 数据管理」确认后清除当前训练数据。此操作不会删除已导出到其他位置的文件，也不会删除导入前保留的本机恢复副本；显示偏好等设备设置也可能仍保留。

删除 App 会移除其应用容器中的本机数据，系统备份的保留与恢复由你的 iOS 设置决定。你自行保存或分享的文件需要到对应位置另外删除。删除 App 前，请先保存仍需要的数据。

资料来源与外部链接

动作资料、支持或隐私链接仅在你主动打开时交由系统处理。外部网站可能接收正常网页访问所需的信息，其处理方式由各网站隐私政策决定。查看内置图示和教学文字不需要打开这些链接。

支持邮件

如果你主动向 gnodstudio@gmail.com 发送邮件，我们会收到你提供的邮箱地址、正文与附件，并仅将它们用于回应请求、排查问题及相关必要沟通。请避免发送密码、支付信息、Apple 账号验证码或不必要的个人资料。

如果希望我们删除你通过支持邮件提供的内容，可以通过同一邮箱提出请求。

本产品网站

本网站只提供产品介绍、静态截图、支持与隐私说明，没有广告、分析代码、第三方字体或跟踪 Cookie，不存储浏览器本地偏好。托管服务 GitHub Pages 可能处理提供网页服务所需的技术日志，详见 GitHub 隐私声明。

儿童与政策更新

循力不通过 App 收集任何用户的个人数据，也不会有意收集儿童的个人数据。训练内容的使用仍应考虑年龄、自身能力及合适的监护和专业指导。

功能或数据处理方式发生变化时，我们会更新本页与生效日期。隐私问题请联系 gnodstudio@gmail.com。
